## Description

Plan: docs/company-pivot-plan.md:162-168. Essential dev loop for iterating on scraper jobs without deploying.

1. New CLI subcommand in packages/sdk/src/cli (entry: packages/sdk/src/cli/index.ts): kitstack job run <name> [--continue-max N]
   - Loads the kit from kit.config.ts in cwd (same loading path the dev/build commands use)
   - Provisions/reuses the local dev DB via provisionDevDb (packages/sdk/src/runtime/dev-db.ts:42, .kitstack/dev.db)

   - Prints run summary (duration, continuations, thrown errors with stack)
2. kitstack job list (and/or in kitstack dev output): show registered jobs + schedules from the kit config.

ACCEPTANCE: in a kit directory with a defineJob, kitstack job run <name> executes against .kitstack/dev.db; errors surface with stack traces; unknown job name gives a clear error listing available jobs.
