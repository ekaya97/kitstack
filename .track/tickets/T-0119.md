## Description

Plan: docs/company-pivot-plan.md:283-315 (3.5 tools table + hybrid search). Tools in kits/freelancer-search/src/tools, following defineTool patterns from kits/crm/src/tools/add-contact.ts:8 (zod args with .describe() on every field, kit.result fragments, snake_case names, descriptions that tell the LLM when to use the tool).

TOOLS:
- search_freelancers: args = query (natural language), skills[], max_rate, availability, location, remote, limit. Hybrid: embed query (same Bedrock model as T-0118) -> vector_top_k over BOTH indexes (freelancer_embeddings + documents.embedding, doc hits mapped to their freelancer) IN PARALLEL with FTS5 BM25 over freelancer_fts -> merge with reciprocal rank fusion -> apply structured filters in SQL. Return ranked compact list; EACH result includes portal profile URL(s). Flag results whose hit came via a document embedding (matched-via-CV).
- get_freelancer: full profile — per-portal source links presented as the ACTION (unlock contact on freelancermap / freelance.de), rates, skills, document list as portal-hosted links, top-N similar freelancers.
- find_similar: vector nearest-neighbors to a given freelancer id.
- search_stats: counts per portal, corpus freshness, last scrape_runs summary.

INSTRUCTIONS (src/instructions.ts, pattern: kits/crm/src/instructions.ts): prefer search_freelancers with a natural-language query then refine with filters; never fabricate rates or contact details (data has none — contact goes through the portal); always present the portal profile link as the action on a match; do not show internal ids.

Query-time embedding runs in the tool handler (kit Lambda has internet after WS2/T-0110). Tune k + RRF constant with a handful of golden queries against a locally-ingested corpus.

ACCEPTANCE: local end-to-end via tool-iterator/kitstack call: a German-language query like erfahrener React Entwickler in Muenchen unter 100 EUR returns sensible ranked results with portal links; filters compose; empty-corpus and no-match paths return helpful text, not errors.
