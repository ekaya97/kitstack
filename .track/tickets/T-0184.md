## Scope
- Expand the `prepare_debrief` input in `kits/debrief/src/contracts.ts` and the kit tool schema: `goal`, `company`, `contact_name`, `location`, `callback_at`, `callback_timezone` (required), optional `buffer_minutes` (default 0).

- Update `DebriefOperations.prepareDebrief` from `(goal, ctx)` to the new input object; keep the four other operations unchanged.
- Fake clock + deterministic scheduler harness in the demo test utilities; contract test that walks the complete presenter sequence.

## Timestamp decision (recorded; override before starting if the presenter wants option B)
- `callback_at` is when the phone rings. `scheduled_call_at = callback_at + buffer_minutes`. `prebrief_ends_at = callback_at`. Both are returned.
- Time-only input resolves to the next occurrence in `callback_timezone`. Missing timezone, a result in the past, or more than 24h ahead fails with an actionable validation error.
