## Goal
Let the presenter confirm structured outcomes in the original Claude thread.

## Scope (tools, Tier 1)
- Add `get_debrief_for_confirmation` (or extend `get_debrief`) returning the confirmation draft plus the `kit_view("debrief","confirmation")` hint.
- Add `update_debrief_draft` (fields: outcome, next step, customer update, discovered address, follow-up date), `confirm_debrief_draft`, and keep `confirm_debrief` outcome `partial`.
- Confirmation writes immutable `debrief_confirmed` and, when an address was discovered, `address_discovered` customer events. Duplicate confirmation returns the same event id.
- Cancel or partial leaves no confirmed event.

## Scope (View, Tier 2)
- Add a `confirmation` View using `useKit().callTool(...)` for mutations and `reload()` after each one (there is no `useTool`; see `packages/sdk/views/src/shared/use-kit.ts`).

## Acceptance
- Presenter says "give me the debrief for confirmation", edits address/next step, confirms, and sees a saved event id.
- Cancel/partial leaves no confirmed event; duplicate confirmation is idempotent.
- Mutation tests pass; kit and demo suites stay green.

## Write scope
`kits/debrief/src/contracts.ts` (additive), `kits/debrief/src/tools`, demo debrief service, `kits/debrief/src/views/confirmation`, mutation tests, host `/mcp` and stdio tool lists.
