## Description

Plan: .track/docs/kitstack-beta-execution-plan.md W6-T1. Review: .track/docs/kitstack-beta-execution-plan-review.md §3.3, §4.

## Scope
- Promote the debrief host's telemetry record to an SDK-owned platform contract: event_id, timestamp, org_id, app_id?, principal, actor, delegation?, session_id, trace_id, parent_id, channel, kit_id, plugin_id, operation, model?, request_tokens?, response_tokens?, cost?, latency_ms, outcome, instruction_id/version?, memory_ids?, error_code?.
- trace_id/parent_id are W3C traceparent-compatible; an inbound traceparent is honored so spans join a gateway's trace.
- Sink with retention/TTL and OTel exporter; org/team/app/session dimensions; per-tool struggle metrics (retries, schema failures, repeated identical calls, tokens per success) as schema fields.
- Negative tests: the record type has no field that can carry prompt, completion, audio, transcript, or payload.

## Acceptance
Debrief host emits through the platform sink with no loss of the /demo screens; an OTel collector receives the spans; the schema test fails if a content field is added.

## Write scope
packages/sdk telemetry types and sink interface, kits/debrief/src/telemetry as first implementation, infra export config.
