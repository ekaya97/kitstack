## Goal

Make the internal capability registry reusable across kits without turning
KitStack into an orchestration framework.

## Scope

- Resolve `PluginRequirement` contracts against registered implementations.
- Support compatible version ranges and stable missing/ambiguous/incompatible
  errors.
- Return resolved capability handles/metadata.
- Preserve current invocation, lifecycle, and compatibility lookup behavior.
- Add focused SDK contract tests.

## Non-goals

Graphs, chains, retries, planners, model routing, marketplace discovery,
dynamic installation, and provider-specific business logic.

## Acceptance

- exact and compatible providers resolve;
- missing, ambiguous, and incompatible providers fail deterministically;
- no debrief files change;
- SDK tests/build pass.
