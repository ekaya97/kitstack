## Goal

Make the local SDK runtime enforce the same authorization contract as the MCP
router and remote adapter.

## Scope

Pass the available `checkAuthz` callback through `packages/sdk/src/server/index.ts`
when it creates `localAdapter`, including the multi-kit and single-kit paths.
Add parity tests for `serve()`, HTTP trigger, schedule/job, daemon/voice
simulator, and router dispatch. Verify assist/use, act, service identity,
delegation, deny-list, and redacted denial audit behavior.

## Acceptance

The same request is allowed or denied identically across local and router
transports; unauthorized local calls have no side effects; tests run with no
external identity provider.

## Parallelism

First P0 ticket. Small SDK-only write scope; do not combine with provider work.
