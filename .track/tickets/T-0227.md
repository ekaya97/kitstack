## Goal

Exercise provider-shaped behavior without Entra, Twilio, CRM, calendar, OTLP,
or cloud credentials.

## Scope

Add deterministic local transports/adapters for an OIDC issuer, voice/media
transport, OTLP collector, and CRM/calendar-shaped connector endpoints. Each
fixture supports success plus expired credential, scope denial, timeout,
rate-limit, malformed response, and provider-unavailable cases. Record only
metadata in telemetry and make calls inspectable by tests and local dashboards.

## Acceptance

The debrief and a generic fixture kit run through normal KitStack dispatch with
the fixtures; every failure mode has an assertion for audit, retry/error
classification, and no secret/content leakage. No network account is needed.

## Parallelism

Can run beside T-0229 after the ticket is accepted. Owns fixtures and test
transports, not the SDK connector contract or platform Views.
