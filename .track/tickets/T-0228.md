## Goal

Make the registry, proxy/connector, observability, FinOps, and audit dashboard
surfaces demonstrable from deterministic local data.

## Scope

Use existing platform data/ViewHost contracts. Add only source-backed fixture
adapters and missing tests for app/plugin registration, binding/scopes,
per-app/session cost, model/tool metadata, trace correlation, audit/export
status, and org filtering. Label fixture data and show empty/unavailable states
honestly.

## Acceptance

One local debrief run and one fixture-kit run produce evidence visible through
the platform Views; an out-of-org event/app is rejected or excluded; no metric
is fabricated and no secret/content appears.

## Parallelism

Start after T-0226 and in parallel with T-0230. Owns platform View/source tests;
do not change connector contracts.
