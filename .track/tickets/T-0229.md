## Goal

Prove that a kit can consume a capability through a reusable connector contract
without knowing the provider implementation.

## Scope

Create a local connector factory and contract suite covering configuration,
binding scope, health, read/write/invoke, pagination, subscribe/sync seams,
normalized errors, retry metadata, and secret-reference redaction. Run the
same suite against REST/OpenAPI, Twilio-shaped, and CRM/calendar-shaped local
fixtures. Keep provider-specific logic out of kits.

## Acceptance

At least two different kits consume different mock implementations through the
same SDK contract; the registry resolves by capability/version; all contract
tests pass without SaaS credentials.

## Parallelism

Can run beside T-0227. Owns SDK connector test/factory scope; the durable
registry persistence is separate in T-0230.
