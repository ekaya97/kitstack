## Goal

Persist the internal reusable capability catalog and scoped provider bindings
without turning it into a marketplace or workflow engine.

## Scope

Persist implementation ID/version, capability contract/version, owner/source,
maturity, required scopes, configuration schema, secret references, runtime
support, contract-test status, and deprecation metadata. Persist org/app/kit
bindings and lifecycle states `declared -> validated -> bound -> ready ->
degraded/failed -> stopped`. Enforce exact org/kit scope and revocation; keep
secret values out of storage and Views.

## Acceptance

A clean local process can restart, reload a binding, resolve a compatible
provider, reject an ambiguous/incompatible provider, and reflect revocation in
the platform registry/dashboard without external infrastructure.

## Parallelism

Start after T-0226 and T-0229. Can run beside T-0228 with a disjoint storage
and binding write scope.
