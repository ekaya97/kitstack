## Goal

Validate selected external providers only after KitStack's local contracts pass.

## Scope

Run conformance evidence for the named pilot's identity provider, voice/SMS
transport, OTLP/SIEM collector, and any CRM/calendar provider. Record setup,
scopes, failure behavior, revocation, cost, and rollback evidence. Do not add a
provider-specific branch to kit code.

## Acceptance

Each selected provider passes the same contract suite as its local mock, or is
marked unsupported with the failing capability and the local fallback retained.

## Note

This ticket is intentionally not on the local beta critical path. T-0201,
T-0203, and T-0204 remain the provider-selection/operator tickets.
