# Industry-Specific Onboarding Checklists

Use these as overlays on the 5-phase methodology. The phase structure stays the same; these checklists add industry-specific tasks and considerations.

---

## Web Development Agencies

### Welcome Phase Additions
- Request hosting credentials (cPanel, Vercel, Netlify, AWS)
- Request domain registrar access or DNS credentials
- Ask about existing tech stack (CMS, frameworks, databases)
- Request current site analytics access (GA4, Search Console)
- Ask about third-party integrations (payment processors, CRMs, email services)
- Request brand kit (logos in SVG/PNG, color codes, fonts, brand guidelines PDF)

### Setup Phase Additions
- Set up staging environment
- Create Git repository and establish branching strategy
- Configure CI/CD pipeline if applicable
- Review existing codebase (if redesign/rebuild)
- Audit current site for SEO baseline metrics
- Document all third-party API keys and services

### Kickoff Phase Additions
- Walk through sitemap and information architecture
- Confirm browser/device support requirements
- Discuss content migration plan (who writes/moves content?)
- Establish design review process (Figma comments, Loom videos, live calls?)
- Confirm who handles domain/DNS changes at launch
- Discuss post-launch support and bug fix window

### First Delivery Additions
- Share design mockups or interactive prototype first (before development)
- Provide staging URL for review, not screenshots
- Include responsive views (mobile, tablet, desktop)
- Document any placeholder content that needs replacement
- Note accessibility compliance status

### Check-In Phase Additions
- Review analytics setup and tracking
- Confirm all forms and integrations are functional
- Discuss ongoing maintenance plan (updates, backups, security)
- Plan training session for CMS if applicable

## Management & Strategy Consulting

### Welcome Phase Additions
- Request organizational chart or team structure
- Ask about previous consulting engagements (what worked, what didn't)
- Request existing strategy documents, board decks, or annual reports
- Clarify decision-making authority (who approves recommendations?)
- Ask about internal politics or sensitivities to navigate
- Request NDA if dealing with confidential business data

### Setup Phase Additions
- Schedule stakeholder interviews (typically 3-8 people)
- Prepare interview guides tailored to each stakeholder role
- Research industry benchmarks and competitor landscape
- Build preliminary hypothesis framework
- Create a data request list (financials, KPIs, customer data)

### Kickoff Phase Additions
- Present the engagement methodology (clients in consulting expect frameworks)
- Clarify what "strategy" means to this client — the word means different things
- Discuss data access and confidentiality protocols
- Agree on deliverable format: slide deck, written report, or both?
- Establish the steering committee cadence (weekly or biweekly)
- Discuss implementation support: are you advising or doing?

### First Delivery Additions
- Deliver a "findings and hypotheses" document before recommendations
- Present to the project sponsor first, then the wider team
- Include data sources and methodology for every finding
- Provide a "so what?" for every insight — never present data without interpretation
- Use the client's language and frameworks, not your consulting firm's proprietary models

### Check-In Phase Additions
- Assess implementation progress on early recommendations
- Offer to present findings to the board or leadership team
- Discuss potential follow-on engagements (naturally, not pushy)
- Provide a transition plan: how the client sustains the work after you leave

## Graphic & Brand Design

### Welcome Phase Additions
- Request brand assets: current logo files, brand guidelines, color palette
- Ask about brand personality (adjectives, mood, reference brands)
- Request examples of designs they like AND designs they hate
- Ask about target audience demographics and psychographics
- Clarify deliverable formats (print vs. digital, dimensions, file types)
- Ask about existing templates, fonts, or design systems in use

### Setup Phase Additions
- Create mood board or style exploration based on intake
- Audit existing brand materials for consistency
- Research competitor visual identities
- Set up design file structure (Figma project, asset library)
- Clarify revision process: how many rounds, what constitutes a "round"?

### Kickoff Phase Additions
- Present mood board or style direction for initial alignment
- Walk through creative brief together
- Discuss "must have" vs. "nice to have" design elements
- Clarify who gives feedback (one person vs. design-by-committee — address this directly)
- Agree on a feedback format: annotated screenshots, written list, or live call
- Set expectations: "We'll present 2-3 concepts, you choose a direction, then we refine"

### First Delivery Additions
- Present concepts in context (mockups on devices, in-situ renders, not flat files)
- Explain the rationale behind each design choice
- Provide a comparison view if presenting multiple directions
- Ask the client to evaluate against the brief, not personal preference
- Include a "Do Not" note if certain feedback would undermine the design system

### Check-In Phase Additions
- Deliver final asset package with all file formats and a usage guide
- Walk through the brand guidelines or style guide
- Offer a "brand training" session for the client's team
- Discuss ongoing design needs (social media templates, marketing collateral)

## Digital Marketing Agencies

### Welcome Phase Additions
- Request access to ad accounts (Google Ads, Meta Business Suite, LinkedIn Campaign Manager)
- Request analytics access (GA4, GTM, Search Console, social analytics)
- Ask about current marketing spend and ROAS expectations
- Request buyer personas or ICP documentation
- Ask about past campaigns: what worked, what flopped, and why
- Clarify reporting expectations: frequency, metrics, format

### Setup Phase Additions
- Audit existing campaigns and performance data
- Set up tracking and conversion events
- Review landing pages for conversion optimization opportunities
- Benchmark current metrics (CPL, CPA, ROAS, CTR, conversion rates)
- Configure reporting dashboard (Looker Studio, Databox, or similar)
- Map the customer journey and identify gaps

### Kickoff Phase Additions
- Present audit findings and initial recommendations
- Align on KPIs and target metrics (be specific: "Reduce CPL from $45 to $30" not "improve leads")
- Discuss brand voice and messaging guidelines for ad copy
- Clarify approval process for creative assets and ad copy
- Agree on testing framework: what you'll test, how you'll measure, when you'll pivot
- Set expectations on ramp-up time ("Month 1 is learning, results accelerate in months 2-3")

### First Delivery Additions
- Launch initial campaigns or optimizations
- Share the first performance report with commentary
- Highlight early signals and what they mean
- Propose the first set of A/B tests
- Provide a 30/60/90-day optimization roadmap

### Check-In Phase Additions
- Review first month's performance against benchmarks
- Adjust strategy based on data (not opinions)
- Discuss budget allocation shifts between channels
- Plan content calendar for next quarter
- Review competitive landscape and emerging opportunities

## Business & Executive Coaching

### Welcome Phase Additions
- Send a pre-coaching assessment or self-evaluation questionnaire
- Ask about their goals: professional, personal, and the intersection
- Request their current role description and organizational context
- Ask about previous coaching or therapy experience
- Clarify confidentiality boundaries (especially if the company is paying)
- Send a coaching agreement outlining expectations, cancellation policy, and commitment

### Setup Phase Additions
- Review assessment results and identify initial focus areas
- Prepare initial session framework (strengths-based, challenge-focused, or exploratory)
- Optionally set up a 360-degree feedback process
- Create a secure document for session notes and progress tracking
- Research the client's industry context if unfamiliar

### Kickoff Phase Additions
- The kickoff IS the first session — don't waste it on logistics
- Establish the coaching relationship: roles, boundaries, candor expectations
- Explore their "big picture" — where they want to be in 1 year, 3 years, 5 years
- Identify the first "leverage point" — the one change that unlocks the most progress
- Agree on between-session commitments (journaling, action items, reading)
- Set the session cadence: weekly, biweekly, or monthly

### First Delivery Additions
- "First delivery" in coaching is the second session — show progress from session 1
- Reference their own words from the kickoff to demonstrate deep listening
- Introduce a framework or tool relevant to their challenge
- Assign a concrete, small action item they can complete before the next session
- Check in async mid-week with a brief encouraging message

### Check-In Phase Additions
- Conduct a formal progress review at session 4-6
- Revisit original goals: still relevant, or have they evolved?
- Ask: "What's been most valuable? What should we change?"
- Discuss the coaching engagement length: continue, extend, or graduate?
- If company-sponsored, prepare a progress summary (with client approval) for the sponsor
