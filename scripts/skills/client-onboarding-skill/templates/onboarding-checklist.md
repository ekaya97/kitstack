## Phase 1: Welcome (Day 0-1)

**Goal:** Confirm the engagement, reduce buyer's remorse, collect essentials.

- [ ] **Send welcome email within 2 hours of contract signing** (you)
  - Reference the specific project
  - Outline what happens next (3-4 bullet points)
  - Attach intake questionnaire
  - Include scheduling link for kickoff
  - Provide direct contact information
- [ ] **Send intake questionnaire** (you)
  - [Service-specific questions — 10-15 max]
  - [Business context questions]
  - [Project-specific questions]
  - [Access and logistics questions]
- [ ] **Request access/credentials** (you)
  - [Platform-specific access needs]
  - [Existing assets and documentation]
  - [Third-party tool logins]
- [ ] **Send first invoice** (you) — [Amount, payment terms]
- [ ] **Schedule kickoff meeting** (you) — target Day [2-5]

---

## Phase 2: Setup (Day 1-3)

**Goal:** Internal preparation so the kickoff is sharp and the client sees a professional operation.

- [ ] **Create project workspace in [PM tool]** (you)
  - [Describe structure: boards, sections, milestones]
  - Pre-populate with project milestones from the proposal
- [ ] **Set up communication channel** (you)
  - [Slack channel / email thread / other]
  - Invite client contacts
  - Pin key links and project overview
- [ ] **Review intake questionnaire responses** (you)
  - Note gaps and follow-up questions for kickoff
  - [Industry-specific review tasks]
- [ ] **[Service-specific setup tasks]** (you)
  - [E.g., audit existing site, research industry, set up dev environment]
- [ ] **Draft kickoff agenda** (you)
  - Send to client at least 24 hours before the meeting
- [ ] **[Assign team roles if applicable]** (you)
  - [Team member]: [responsibility]
  - [Team member]: [responsibility]
  - You: [responsibility]

---

## Phase 3: Kickoff (Day 3-5)

**Goal:** Align on goals, process, and expectations. Build rapport.

- [ ] **Confirm kickoff attendees** (you → client)
  - Client side: [who should attend and why]
  - Your side: [who from your team]
- [ ] **Run kickoff meeting ([duration] min)** (you facilitates)
  1. Introductions and roles ([X] min)
  2. Project goals and success metrics ([X] min)
  3. [Service-specific agenda items] ([X] min)
  4. Scope and timeline walkthrough ([X] min)
  5. Communication plan and cadence ([X] min)
  6. Immediate next steps ([X] min)
  7. Questions and concerns ([X] min)
- [ ] **Send kickoff summary within 24 hours** (you)
  - Project goals confirmed
  - Key decisions made
  - Action items with owners and deadlines
  - Updated timeline
  - Next touchpoint date
- [ ] **Share project workspace with client** (you)
  - [Appropriate access level]
- [ ] **Create stakeholder contact sheet** (you)
  - [Name, role, contact, decision authority]

---

## Phase 4: First Delivery (Day [5-14])

**Goal:** Deliver the first tangible output, establish the feedback loop.

- [ ] **Complete first deliverable** (you/team) — target Day [X]
  - [Describe the first deliverable for this service type]
  - [Internal quality review before sending]
- [ ] **Send deliverable with context** (you)
  - What was delivered and approach taken
  - Specific feedback questions (3-5):
    1. "[Specific question about direction/approach]"
    2. "[Specific question about quality/accuracy]"
    3. "[Specific question about completeness]"
  - Revision timeline
  - Next milestone preview
- [ ] **Follow up if no feedback in 48 hours** (you)
  - Brief, friendly nudge via [preferred channel]
  - Offer a call if easier than written feedback
- [ ] **Process feedback and deliver revisions** (you/team)
  - Within [X] business days of receiving feedback

---

## Phase 5: Check-In (Day [14-30])

**Goal:** Review the process, surface concerns, adjust for the rest of the engagement.

- [ ] **Schedule check-in** (you) — [X]-minute call or async survey
- [ ] **Ask process questions** (you)
  - "How is the communication working?"
  - "Is the pace meeting your expectations?"
  - "What would you change about how we work together?"
  - "Any concerns about the timeline or upcoming milestones?"
  - "Is there anything you haven't brought up yet?"
- [ ] **Document feedback and action items** (you)
- [ ] **Implement process changes within 1 week** (you)
  - Confirm changes to client
- [ ] **[Engagement-specific check-in tasks]**
  - [E.g., retainer hours review, ongoing cadence setup, referral/testimonial ask]

---

> **Customization notes:**
> - For **solo freelancers**: Remove team assignment tasks, simplify the PM setup, combine setup and kickoff phases if the project is small.
> - For **agencies**: Add internal briefing steps, designer/developer handoff tasks, and quality review gates.
> - For **retainers**: Add monthly reporting, hours tracking, request workflow, and rollover policy.
> - For **short engagements** (< 4 weeks): Compress Phases 1-3 into 2 days, move the check-in to the midpoint.
> - For **enterprise clients**: Add procurement/legal coordination, multiple stakeholder management, and formal reporting cadence.
