# Authorization

Tool-level authorization is available now. Tools declare requirements with an `authorize` hook, and the server checks them with a `checkAuthz` function.

`kitstack dev` and `kitstack call` do not enforce `authorize` hooks (they print a warning). `kitstack serve` and `serve()` are fail-closed: such tools are denied unless you pass `checkAuthz` to `serve()`, or start `kitstack serve --unsafe-skip-authz` for local development. `createTestKit()` accepts `checkAuthz` for tests.

See the [Authorization guide](/docs/guides/authorization) for examples.
