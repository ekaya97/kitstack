# Roadmap

KitStack is under active development. Here's what we're building next.

## Try it out

Try kits and skills directly on KitStack before committing to anything. Browse the marketplace, activate a kit, and use it in your LLM client — free, with usage limits. No credit card, no setup.

## Skill customizer

A guided customization flow for skills (skills are free forever). Take any skill from the marketplace and personalize it for your specific use case — adjust prompts, configure behavior, make it yours. Built into the platform, no code required.

## KitBuild

A web-based kit builder with AI integration. Describe what you want, and KitBuild scaffolds the tools, views, schema, and instructions for you. Edit in the browser, preview live, deploy with one click. Think Lovable, but for MCP apps.

## Kit bundles

Bundle multiple kits to combine functionality. A CRM kit + a customer support kit, for example. The platform joins the individual databases at runtime so kits can share data and work together — without either kit author needing to know about the other.

## Multi-tenant databases with authorization

An opt-in kit config for shared databases. Multiple users connect to the same database with fine-grained, Google Zanzibar-style authorization built into the SDK. Define who can read, write, and own which resources — the `authorize` hook on tools enforces it automatically.

This unlocks team use cases: shared CRMs, collaborative project trackers, multi-user dashboards — all with per-resource access control out of the box.

## Per-kit billing and admin dashboard

Kit authors can charge for their kits — subscription, usage-based, or one-time purchase. The platform handles billing and payments for a fee. A dedicated kit admin dashboard provides insights into users, activation status, kit logs, and revenue.
